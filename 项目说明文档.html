📋 1. 项目概述

本项目是一个完整的物联网(IoT)解决方案，通过中国移动OneNET云平台实现STM32F103硬件终端与微信小程序之间的双向数据通信与远程控制。系统包含三个独立硬件模块（光照传感器、人体感应传感器、蜂鸣器）和一个微信小程序控制端，可应用于智能家居、环境监测、安防联动等场景。

核心功能

☀️ 光照采集与智能控灯

ADC采集环境光照强度(Lux)，支持自动模式（暗时开灯/亮时关灯）与手动远程控制

👤 人体感应检测

HC-SR501 PIR传感器实时检测人体活动，有人时亮灯提示

🔊 蜂鸣器报警

间歇式蜂鸣控制（响1秒停2秒），支持手动开关和场景联动触发

📱 微信小程序监控

实时仪表盘、历史趋势图、照明/蜂鸣器远程控制、多设备配置管理

🔗 跨设备场景联动

光照≥3000 Lux时自动触发蜂鸣器，实现设备间M2M自动协同

💾 本地数据持久化

IndexedDB存储历史传感器数据与设备配置，支持离线查看

🔧 3. 硬件模块详解

三个硬件模块均采用 STM32F103 作为主控芯片，通过 ESP8266 WiFi模块连接网络，运行 FreeRTOS 环境（RTE），使用 Keil MDK 开发。

☀️
光照传感器模块
设备名：addp_01
  • 主控：STM32F103
  • 传感器：模拟光照传感器 (PA7 / ADC1_CH7)
  • 输出：PB1 绿色LED（低电平有效）
  • 显示：OLED (I2C)
  • 自动模式：光照 < 1000 Lux → 开灯；光照 ≥ 1000 Lux → 关灯
  • TIM2定时器：100ms周期检查光照阈值
  • 手动模式：小程序下发 led: true/false
  • ADC校准：两点线性插值 (1200→300Lux, 3000→8000Lux)
  • 上报周期：每1秒 (10×100ms)
  • 上报数据：light (光照值), led_mode (模式)
👤
人体感应模块
设备名：addp_02
  • 主控：STM32F103
  • 传感器：HC-SR501 PIR人体红外传感器 (PA4)
  • 输出：PB1 绿色LED
  • 显示：OLED
  • 逻辑：有人(低电平) → LED开；无人(高电平) → LED关
  • 上报周期：每1秒 (10×100ms)
  • 上报数据：Pir (bool, true=无人 / false=有人)
🔊
蜂鸣器模块
设备名：addp_03
  • 主控：STM32F103
  • 执行器：有源蜂鸣器 (PA6)
  • 间歇模式：响1秒 → 停2秒 → 循环 (100ms/tick)
  • 控制方式：手动（小程序）或联动（光照模块触发）
  • 联动触发条件：光照≥3000 Lux
  • 上报周期：每3秒 (30×100ms)
  • 上报数据：buzzer_switch (bool)

光照模块关键代码逻辑

// TIM2中断：自动模式下的光照控制 (100ms周期)
void TIM2_IRQHandler(void) {
    if(TIM_GetITStatus(TIM2, TIM_IT_Update) != RESET) {
        TIM_ClearITPendingBit(TIM2, TIM_IT_Update);
        if(led_mode == 0) {  // 自动模式
            if(light < 1000) LED_Green_On();
            else             LED_Green_Off();
        }
    }
}

// 光照采集：ADC10次采样取平均 → 线性插值转Lux
uint16_t Light_GetLux(void) {
    uint16_t adc = Light_GetAdcAverage(); // 10次均值
    float lux = (adc - 1200) * (8000 - 300)
                / (3000 - 1200) + 300;
    return (uint16_t)lux;
}

🔗 6. 场景联动机制

这是本项目最具特色的功能：硬件设备之间通过 OneNET MQTT 消息实现 M2M (Machine-to-Machine) 自动协同，无需小程序或云端规则引擎参与。

联动规则

☀️
触发条件
光照模块 (addp_01) 检测到环境光照 ≥ 3000 Lux
📤
MQTT发布
光照模块直接向主题 $sys/182uSs4N9a/addp_03/thing/property/set 发布消息 {"buzzer_switch":{"value":true}}
🔊
蜂鸣器响应
蜂鸣器模块 (addp_03) 收到MQTT消息后，开启间歇蜂鸣（响1秒停2秒循环）

此联动代码位于光照模块的 onenet.c 中：

void OneNET_PushLightToFan(void) {
    static u8 last_buzzer_cmd = 0;
    u8 should_buzzer_on = (light >= 3000) ? 1 : 0;
    
    if(should_buzzer_on != last_buzzer_cmd) {  // 仅状态变化时发送
        last_buzzer_cmd = should_buzzer_on;
        snprintf(topic, ..., "$sys/%s/addp_03/thing/property/set", ...);
        snprintf(msg, ..., "{\"buzzer_switch\":{\"value\":%s}}", ...);
        OneNET_Publish(topic, msg);  // 跨设备MQTT消息
    }
}

该方法在光照模块的主循环中每1秒调用一次（与数据上报同频）。仅在状态变化时发送，避免重复消息。

🚀 7. 部署与配置指南

硬件部署

  1. 使用 Keil MDK 分别打开三个模块的 stm32f103.uvprojx 工程文件
  2. 编译并烧录到对应的 STM32F103 开发板
  3. 确保 ESP8266 WiFi 模块已配置好 SSID 和密码（在 esp8266.h 中配置）
  4. 上电后设备自动连接 WiFi → 连接 OneNET MQTT → 订阅控制主题 → 开始上报数据
  5. 通过串口3 (115200bps) 可观察调试日志，确认连接状态和数据上报

微信小程序部署

  1. 使用微信开发者工具打开 miniprogram-1 - 副本 目录
  2. AppID 已配置为 wxce1461b726368140
  3. 在「设备配置」页面填入 OneNET 产品ID 和 Access Key
  4. 确认三个设备名称与 OneNET 平台注册的设备名一致
  5. 点击「测试连接」验证配置正确性
  6. 进入「设备监控」页面即可查看实时数据和进行远程控制

OneNET平台配置

  1. 登录 OneNET开放平台
  2. 创建MQTT产品，获取产品ID (Product ID)
  3. 在「设备管理」中添加三个设备：addp_01（光照）、addp_02（人体）、addp_03（蜂鸣器）
  4. 在「物模型」中为每个设备定义属性：光照设备定义 light 和 led，人体设备定义 Pir，蜂鸣器设备定义 buzzer_switch
  5. 获取 Access Key（产品详情页 → 接入认证）
